# AI大学学习伙伴

面向大学生的单文件 AI 学习助手 —— 一个 HTML 文件，双击（或本地起个服务）就能用。

## 它是什么

内置五个 AI 角色，跨角色共享「学生画像」，越聊越懂你：

| 角色 | 能力 |
|---|---|
| 📚 学科教师 | 高等数学（同济七版）、C / Python / Java，推导不跳步 |
| 🌿 心理老师 | 情绪陪伴、压力疏导，高危表达自动弹出求助资源 |
| 📅 生活规划 | 课表 / 日程 / 考研考公规划 |
| 💚 健康助手 | 作息 / 饮食 / 运动科普（不诊断、不开药） |
| 💰 理财助手 | 生活费 / 消费观念（不荐股、不荐基） |

亮点：

- **云端 / 本地双模式**：云端模式一键接入硅基流动、通义千问、魔搭等免费大模型 API，填一个 Key 零部署即用；本地模式对接 LM Studio / Ollama，完全离线
- **学生画像自动沉淀**：对话中提到的学业、情绪、作息、消费信息自动写入结构化档案，切换角色时主动引用
- **演示模式**：无网络、无模型也能完整演示流式输出与画像积累（评委/新用户零门槛）
- **语音通话**：Web Speech API 驱动的全屏语音对话
- **零依赖**：单 HTML 文件，无框架、无构建、无后端，配置只存本机浏览器

## 快速开始

```bash
# 推荐用本地服务打开（不要双击 file://）
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

首次打开会有知情同意页；未配置模型时自动进入演示模式。

### 接入云端免费 AI（推荐，1 分钟）

详见 [云端AI接入指南.md](./云端AI接入指南.md)：

1. 到 [硅基流动](https://cloud.siliconflow.cn/account/ak) 注册并创建 API Key
2. 应用左下角「⚙ AI 设置」→ 云端 AI → 粘贴 Key
3. 点「测试连接」→ 通过后保存

### 使用本地模型

LM Studio 默认 `http://localhost:1234/v1/chat/completions`（记得勾选 Enable CORS）；
Ollama 默认 `http://localhost:11434/v1/chat/completions`（用 `OLLAMA_ORIGINS=* ollama serve` 启动）。

### 智谱等不允许浏览器直连的厂商

仓库内附带零依赖中转脚本：

```bash
python AI学习伙伴-proxy.py
# 接口地址填 http://localhost:8787/v1/chat/completions
```

## 隐私与安全

- 所有对话、配置、学生画像只保存在浏览器 localStorage，不上传任何服务器
- API Key 只存在本机；「恢复默认」可一键清空
- 心理 / 健康模块内置免责声明与高危求助干预（全国心理援助热线 12356 等）
